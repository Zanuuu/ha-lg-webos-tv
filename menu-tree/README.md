# Arbre des menus

Fichiers JSON déclaratifs décrivant le menu Réglages du LG OLED 65 G5
(webOS 25), construits en phase 2 :

1. transcription depuis le guide d'utilisation LG G5 français ;
2. rapprochement avec les clés API inventoriées en phase 1 ;
3. vérification contre les photos des menus réels fournies par l'utilisateur.

Aucun libellé, description ou valeur ne doit être inventé : ce qui manque est
marqué « à vérifier ». Le schéma JSON des entrées est défini en phase 2.
